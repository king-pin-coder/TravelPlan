# Karnataka 2026 road-trip mobile guide — real photo edition

This version removes **all illustrated image placeholders**. Photograph URLs were selected using location and food searches, including Google-indexed places and images from destination, hospitality and editorial sites. No Google Maps API key is needed. Each card has a direct **Photos on Google** action to check exact-place pictures.

## Publish

Upload `index.html` and `.nojekyll` to a GitHub repository root and enable GitHub Pages (Settings > Pages > Deploy from branch > main / root).

## Image limitations

Photographs are hotlinked from source websites: internet access is needed and some hosts may block embedding. Cards with no verified photograph offer Google Images search rather than an unrelated picture. **Not every card has a unique photograph**: drive segments and repeated visits to the same hotel can appropriately share a real photograph, labelled as such. A photo of the wider region is explicitly labelled as a regional photo and should not be mistaken for the exact building.

The fact that a travel website is intended for personal viewing does not automatically waive third-party photo copyright, and a regular GitHub Pages website is publicly reachable. Review the terms of photo hosts before relying on this published site. Source links are included in the guide.

The interface retains seven-day independent swipe navigation, scheduled Today / Now, India time, visited tracking in localStorage and Google Maps route links.
